# Chrome 滚轮缩放 · 使用说明

一个 macOS 菜单栏工具，让 Google Chrome 支持 **Control（⌃）＋鼠标滚轮**进行页面缩放。它调用 Chrome 自身的缩放功能，普通网页的缩放档位和网站缩放记忆由 Chrome 管理。

## 下载安装

1. 打开本项目的 **Releases**，下载最新版本的 `.dmg` 并打开；也可下载 `.zip` 并解压。
2. 将 **Chrome 滚轮缩放.app** 拖到 Mac 的“应用程序”文件夹，再从那里打开。
3. 启动后，屏幕顶部菜单栏会出现 **⌃↕**。这是菜单栏工具，不显示 Dock 图标。

发布包为 **Universal 应用，构建目标为 macOS 13 或更高版本**，包含 Apple Silicon 和 Intel 两种架构。已在 Apple Silicon 上验证；Intel 和其他 macOS 版本尚未实机验证。

### 首次打开时被系统拦截

此版本使用本地 ad hoc 签名，**没有 Apple Developer ID 签名，也未经过 Apple 公证**。本地签名不代表 Apple 已验证开发者身份或检查过软件。

确认下载来自本项目、愿意信任此软件后，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 操作：

1. 先尝试打开应用。
2. 打开“系统设置”→“隐私与安全性”，向下找到对应提示，点击“仍要打开”。
3. 在再次出现的提示中点击“打开”；如系统要求，在系统窗口完成身份验证。

只为这个应用添加例外即可，无需关闭 Gatekeeper。若系统提示应用已损坏或包含恶意内容，请先停止安装并核查下载文件。

## 开启辅助功能权限

1. 在工具窗口点击“打开辅助功能设置”，或点击菜单栏 **⌃↕** →“打开辅助功能设置…”。
2. 在系统设置中找到 **Chrome 滚轮缩放**，开启其权限；如未列出，可用“＋”添加“应用程序”中的该应用。
3. 如系统要求，在系统窗口完成密码或触控 ID 验证，不要向任何人提供密码。
4. 返回菜单栏，状态显示 **“已启用 · 仅在 Chrome 中生效”** 即可使用。

相应页面在部分 macOS 版本中叫“辅助功能”；已测试的 macOS 27 将其显示为 **“设备控制和数据访问”**。授权后工具会自动检查权限，通常无需重启。

## 日常使用

先让 Google Chrome 成为前台应用，再进行以下操作：

| 操作 | 效果 |
| --- | --- |
| 按住 Control（⌃），滚轮向上 | 放大 |
| 按住 Control（⌃），滚轮向下 | 缩小 |
| ⌘0 | 恢复 Chrome 默认缩放比例 |
| 松开 Control 后滚动 | 正常滚动页面 |

这里的 Control 是 **⌃**，不是 Command（⌘）。同时按住 Shift、Option 或 Command 时，工具不会接管滚轮。

点击菜单栏 **⌃↕** 可以：

- 取消勾选“启用 Ctrl + 滚轮缩放”来暂停，再次勾选即可恢复。
- 勾选“反转缩放方向”；这个设置会保存在本机。
- 打开使用说明和权限设置。
- 选择“退出 Chrome 滚轮缩放”，立即停止处理滚轮。

## 重启后运行

默认**不设置开机或登录自启**，重启 Mac 后需要重新打开应用。

如需自动启动，可在“系统设置”→“通用”→“登录项”（部分版本显示“登录项与扩展”）的“登录时打开”列表中，用“＋”添加 **Chrome 滚轮缩放.app**。不再需要时，从该列表移除即可。

## 兼容范围

- 仅接管前台的 **Google Chrome 稳定版**；Chrome Beta、Canary、Chromium、Edge、Brave 和其他应用不在当前范围内。
- 使用 Chrome 原生的 ⌘＝ / ⌘－ 快捷键。Chrome 限制缩放的页面仍受浏览器限制；PDF、本地图片等界面的效果由 Chrome 自己决定，其中 PDF 尚未单独实测。
- 普通触控板捏合保持原有行为。Control＋触控板滚动及连续滚轮采用累积位移换档，并忽略惯性；不同设备的手感可能与 Windows 驱动有所不同。
- 方向会适配 macOS 的“自然滚动”；如果鼠标驱动使方向相反，可使用菜单中的“反转缩放方向”。
- 若 macOS 的系统级缩放也绑定了 Control＋滚轮，请到“系统设置”→“辅助功能”→“缩放”检查冲突，调整系统缩放的修饰键。
- 发送的快捷键按 ANSI 键盘的 `=` / `-` 键位实现。其他键盘布局和第三方鼠标驱动尚未单独实测。

## 无法使用时

1. 确认菜单栏 **⌃↕** 已出现，且状态为“已启用 · 仅在 Chrome 中生效”。
2. 确认当前前台应用是 Google Chrome 稳定版，使用的是 Control（⌃）键。
3. 若状态显示“等待开启辅助功能权限”，重新检查系统中的应用权限。
4. 若显示“监听未启动”，先退出工具，再重新打开。更新应用或重新签名后，macOS 可能要求重新授权。
5. 检查系统缩放及鼠标驱动是否也处理了 Control＋滚轮。

## 隐私与权限

工具通过 macOS 滚轮事件检查 Control 状态和前台应用，只向符合条件的 Chrome 进程发送缩放快捷键。**不订阅键盘输入，不读取网页内容，不记录滚轮或按键事件，不发起网络请求**。仅将“反转缩放方向”偏好保存在本机。

辅助功能是 macOS 提供的较宽权限，上述处理范围由公开源代码实现。

## 卸载

1. 点击菜单栏 **⌃↕** →“退出 Chrome 滚轮缩放”。
2. 如添加过登录项，将它从“登录时打开”列表移除。
3. 将“应用程序”中的 **Chrome 滚轮缩放.app** 移到废纸篓。
4. 在系统设置的辅助功能权限列表中关闭或移除该应用。

退出或卸载后，Chrome 与系统恢复原有的滚轮行为。
