# v1.0.0

首次公开发布 · 2026-10-17

Chrome 滚轮缩放是一个 macOS 菜单栏工具，为 Google Chrome 稳定版提供 **Control（⌃）＋滚轮**页面缩放。

## 功能

- Chrome 位于前台时，Control＋滚轮向上放大、向下缩小；松开 Control 后正常滚动。
- 使用 Chrome 原生缩放，支持 ⌘0 恢复默认比例。
- 菜单栏 **⌃↕** 提供暂停、反转方向、权限入口和退出。
- 适配自然滚动方向，连续滚动采用累积换档并忽略惯性。
- 不读取网页、不记录输入、不联网；默认不添加登录项。

## 下载与首次运行

从本版本的 **Assets** 下载 `.dmg` 并打开，或下载 `.zip` 并解压，然后将应用拖入“应用程序”文件夹。发布包包含 Apple Silicon 与 Intel 架构，构建目标为 macOS 13 或更高版本。

应用采用 **ad hoc 本地签名，未使用 Apple Developer ID 签名，未经过 Apple 公证**，首次打开可能被系统拦截。确认来源可信后，可按 [Apple 官方流程](https://support.apple.com/zh-cn/102445)，先尝试打开，再在“系统设置”→“隐私与安全性”中选择“仍要打开”。无需关闭 Gatekeeper。

首次运行还需为 **Chrome 滚轮缩放** 开启辅助功能权限。已测试的 macOS 27 将相应页面显示为“设备控制和数据访问”。完整步骤见[使用说明](使用说明.md)。

## 验证与已知边界

- 已验证环境：Apple Silicon、macOS 27.0.1、Google Chrome 155.0.8059.84。
- 53 项滚轮行为检查通过；Chrome 原生缩放快捷键和普通滚动已实测。
- 用户已用实体鼠标确认 Control＋滚轮可以正常放大和缩小。
- Intel、其他 macOS 版本、PDF、其他键盘布局和第三方鼠标驱动尚未单独实测。
- 当前仅支持 Google Chrome 稳定版；其他 Chromium 浏览器及 Chrome 预览版本不在接管范围。
- Chrome 自身限制缩放的界面仍受其限制；连续滚轮及触控板手感不能保证与所有 Windows 鼠标驱动一致。
