# v1.1.0 · 通用滚轮缩放

本版将“Chrome 滚轮缩放”扩展为 **通用滚轮缩放**：在支持原生内容缩放的应用中，用 Control（⌃）＋滚轮调用应用自己的放大、缩小功能。GitHub 仓库地址保持不变。

## 主要变化

- 根据前台应用的原生菜单自动识别成对的放大、缩小命令，通过辅助功能执行菜单动作。
- 扩展到可识别原生缩放菜单的应用，包括 Edge、VS Code、Codex 等；未识别到对应能力或命令不可用时，保持原有滚轮行为。
- 为豆包单独适配“放大字体／默认字体／缩小字体”。这个字体菜单别名仅用于豆包。
- 菜单栏显示当前应用的缩放能力，支持调用当前应用的恢复默认命令；部分应用没有此命令。
- 保留暂停、反转方向、连续滚轮累积阈值和触控板惯性过滤。
- 新增只读的原生菜单检测：读取标题、层级、可用状态及动作，不读取网页、聊天或文档正文，不记录输入，不联网。

应用自己的缩放能力决定实际范围与效果。菜单存在不代表每个子界面都能缩放，也不保证所有 macOS 应用都提供内容缩放。

## 安装包

- `ScrollZoom-1.1.0-universal.dmg`
- `ScrollZoom-1.1.0-universal.zip`
- `SHA256SUMS.txt`

应用名称为 **通用滚轮缩放.app**。Universal 包含 Apple Silicon（arm64）与 Intel（x86_64）架构，构建目标为 macOS 13 或更高版本。应用使用本地 ad hoc 签名，尚无 Apple Developer ID 签名和 Apple 公证。

## 从 v1.0.0 升级

先在菜单栏退出“Chrome 滚轮缩放”，移除旧应用，再安装“通用滚轮缩放”。macOS 可能要求重新授予辅助功能权限；如设置过登录项，请同步替换为新版。反转方向偏好沿用旧版设置。

## 验证范围

- 53 项滚轮计算检查、38 项缩放策略检查通过。
- 用户实体鼠标验收通过：Edge、VS Code、豆包、Codex 四个应用中，Control＋滚轮向上放大、向下缩小均正常。
- 其他应用及各应用的所有子界面未逐一验收；原生缩放能力决定实际支持范围。
- Intel、macOS 13～26、所有应用版本、PDF 以及不同鼠标驱动未逐一实测。
